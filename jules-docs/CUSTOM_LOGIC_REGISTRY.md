# Custom Business Logic Registry

| Logic Domain | Location (File:Line) | Plain-English Description | Handled Edge Cases | Known Unhandled Edge Cases |
| :--- | :--- | :--- | :--- | :--- |
| **AuditLog Immutability** | `server/src/models/AuditLog.js` | Enforces absolute log immutability via Mongoose `pre-save` and `pre` hooks for update/delete operations (`updateOne`, `deleteMany`, etc.) to prevent malicious log tampering. | Blocks direct database mutations, `save()` modifications on fetched log objects, and query-based deletions. | Bypassable only through direct MongoDB shell commands with root administrative database credentials. |
| **Clan Chief Lookup Caching** | `server/src/services/clanScope.service.js` | Optimizes role/chief permission checks by caching clan-to-chief mappings in an extensible, scalable cache class provider `ChiefClanCacheProvider` and clearing it dynamically on any Clan mutations (`save`, `insertMany`, `updateOne`, etc.). Uses async interfaces and returns hit status objects to prevent negative-cache Stampedes. | High-concurrency operations, stale cache avoidance, and negative cached `null` results properly cached without database stampedes. easily swappable with Redis. | Needs real Redis integration library if deploying in stateless multi-container clusters. |
| **XP & Points Assignment** | `server/utils/xp.js` | Automatically assigns hardcoded points based on difficulty levels when creating challenges or calculating daily login rewards. | Handles fallback defaults if user-supplied challenge points are absent during custom creation. | Point values are static; no dynamic weighting based on challenge duration or solving time. |
| **Daily Login XP Logic** | `server/utils/dailyLoginXp.js` | Automatically awards 50 points to users once per day upon calling the `/api/auth/me` endpoint after completing onboarding. | Correctly handles timezone date rollover, prevents multiple awards on the same calendar day, and inserts a corresponding XpLog entry. | Relies on server timezone; user timezone differences can lead to perceived delayed rollovers. |
| **Badge RBAC Constraints** | `server/src/controllers/badge.controller.js` | Controls badge administration: restricts chief badge pool awarding and revoking strictly to Admins and Clan Chiefs, preventing cross-clan awarding or self-awarding. | Validates target member is in the Chief's own clan, and blocks self-badge assignment. | Does not prevent an Admin from assigning cross-clan badges (intentional, as Admins have global moderator powers). |
